# Portfolio de Enzo Cespedes

## Qué es
Página personal de una sola hoja que muestra el trabajo real de un desarrollador full stack (backend Node.js + SQL Server) con cinco años haciendo sistemas de gestión y tres migraciones de sistemas legacy.

## Para quién
- Reclutadores de empresas de software argentinas: miran 30 segundos, buscan puesto, tecnologías y números.
- Líderes técnicos que evalúan: quieren detalle de proyectos, método y de dónde salen los números.

## Qué tiene que lograr
Que lo llamen para un puesto de desarrollador y que le crean. Arriba lo rápido, abajo el detalle.

## Verdades del producto
- Los números salen de partes de horas, historial de git y GitHub. Nada inventado.
- Sin nombres de clientes ni del estudio. Sin código.
- Voz directa, rioplatense, sin lenguaje inflado. "Primero el problema, después la tecnología."

## Restricciones
- Un solo archivo estático, publicable en GitHub Pages.
- Tiene que leerse bien en celular.
- No debe parecer una plantilla de portfolio generada.
