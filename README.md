# Portfolio — Enzo Cespedes

Página personal de una sola hoja (`index.html`), sin dependencias ni build.

Los números salen de mis partes de trabajo, del historial de git y de GitHub. No hay código ni datos de clientes.

## Ver en local
Abrir `index.html` en el navegador.

## Publicar en GitHub Pages
1. Repo público `enzojoelc/portfolio`, rama `main`.
2. En el repo: Settings → Pages → Source: "Deploy from a branch" → `main` / raíz.
3. Queda en `https://enzojoelc.github.io/portfolio/`.

## Notas
- Las tipografías (Bricolage Grotesque y Hanken Grotesk) se cargan desde Google Fonts: sin internet cae a la fuente de respaldo.
- `PRODUCT.md` describe para quién es la página y qué tiene que lograr.
